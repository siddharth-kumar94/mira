# Proxy

Last verified: f064d7ee53a4 on 2026-10-20 (live)

The FastAPI proxy between the browser and Rally WSAPI. It holds the API key, maps Rally's shapes to Mira's domain objects (only `server/app/rally/` knows Rally's shapes), enforces the demo write guard, and answers every `/api/*` route. It has no screen of its own: the key is entered in Settings › Account (see connect-settings), and everything else reaches it through the client. Overall: beta, because the two big reads are slow on this workspace and the portfolio priority write has never run live.

## How to get to it (user POV)

No user path: the proxy is reached through the client. A person connects the key in "Settings" › "Account" (see connect-settings). The 127.0.0.1 and localhost hosts are the only ones it answers (`server/app/main.py:49`).

## Driving it

Preconditions: baseline.

- **proxy-session**, **proxy-write-guard-issues**, **proxy-issue-writes**, **proxy-updates**, **proxy-mapping**, **proxy-portfolio-reads**: → `rallypoc check api` → every `api:*` line PASS except `api:cycle-detail-art` and `api:pm-priority`, which SKIP with a reason.
- **proxy-team-reads**: → `curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:8787/api/bootstrap` → 200; time `GET /api/teams/<id>` for the larger team and expect seconds, not milliseconds.
- **proxy-write-guard-portfolio**: → `rallypoc test` → `test_guard.py` and `test_portfolio.py` pass; the live allowed path is `api:update-round-trip`.
- **proxy-burnup**: → `rallypoc api GET "/api/burnup?team=<id>&cycle=<current>" --expect 200` → the last point's scope, started and completed equal the sprint's stats in `GET /api/teams/<id>/cycles`; `rallypoc api GET /api/burnup --expect 422` (no target).
- **proxy-disconnect**: not driven live. Never click Disconnect or send `DELETE /api/session` on the user's key.

## Gotchas

- **Two reads are slow.** `GET /api/teams/<id>` for AI/ML Solutions took 12.9 s and `GET /api/initiatives` 11 s on 2026-10-20 (workspace features 2.9 s, bootstrap 1.7 s, sprints 0.9 s). The client shows a loading line for the whole time. Caches make a repeat call under a second for a minute or so (`rally/portfolio.py:41` caches blocked counts).
- **Rally work rules block starting a [DEMO] Feature.** Moving a Feature to Current PI needs Financial Work Type and Investment Category, which the seed cannot supply, so the demo Features stay in the Backlog category (see features and updates-health).
- **The guard has no off switch in the UI.** Only `rallypoc stack up --write-guard off` changes it, and the verify checks refuse to run then (`rallypoc:722`).
- **Fixtures are synthetic.** Never copy real ObjectIDs into tests or this map.
